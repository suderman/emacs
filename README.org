* About

This is the Emacs config I use every day on NixOS. I tune it around how I edit,
switch projects, and manage windows. It is not a starter kit, and I do not try
to make it portable to systems I do not use.

[[https://github.com/meow-edit/meow][Meow]] controls modal editing. Built-in =project.el= supplies project data.
IBuffer shows open buffers by project, Treemacs keeps the current project
visible, and Magit handles Git. Vertico, Orderless, Consult, Marginalia, and
Embark handle minibuffer completion.

Some choices are a little odd on purpose. Comma opens IBuffer, period opens
Dirvish, and apostrophe repeats edits. =SPC= is both Meow's keypad and my leader
key. IBuffer and Treemacs pass file and project context back and forth instead
of acting like separate tools.

The editing map starts with selections, then applies changes to them. Dirvish
cleans up Dired. Markdown preview runs Pandoc and refreshes after each save.
Stylix supplies the colors, while Doom Modeline and Nerd Icons handle the lower
status bar and file symbols. Image mode cycles through a directory, transforms
images in place, and starts animated images automatically.

* NixOS owns half of it

This repository cannot reproduce my Emacs on its own. The matching
[[https://github.com/suderman/nixos][suderman/nixos]] flake installs Emacs 31 PGTK, the daemon and client,
tree-sitter grammars, native packages, language servers, formatters, Pandoc,
and fonts. Stylix chooses the theme and typography.

This repository installs pure Elisp packages and defines commands, keymaps, and
editing behavior. Package data and runtime state use XDG paths, so they do not
end up in Git.

Read [[file:AGENTS.md][AGENTS.md]] before changing the structure. It explains which repository owns
each package, what each module does, where hot reload has failed before, and how
I test changes.

** Git

Magit is the repository dashboard. It stages files, hunks, and selected lines;
drives commits, branches, remotes, logs, diffs, stashes, rebases, and other Git
operations through its native Transient menus. Meow stays off in Magit buffers
so those native single-letter commands win.

| Key         | Action                                  |
|-------------+-----------------------------------------|
| =SPC . .=   | Open Magit status                       |
| =SPC . m=   | Open Magit dispatch                     |
| =SPC . f=   | Open current-file dispatch              |
| =SPC . d=   | Diff the current file                   |
| =SPC . l=   | Show current-file history               |
| =SPC . b=   | Show current-line blame                 |
| =SPC . B=   | Show full-buffer blame                  |

diff-hl updates change indicators while editing. Its hunk commands are grouped
under =SPC . h=.

| Key           | Action                         |
|---------------+--------------------------------|
| =SPC . h n/p= | Next / previous hunk           |
| =SPC . h v=   | Preview hunk                   |
| =SPC . h d=   | Open hunk in a diff            |
| =SPC . h s=   | Stage hunk                     |
| =SPC . h r=   | Revert hunk                    |
| =SPC . h u=   | Unstage the current file       |

Built-in smerge-mode and Ediff handle conflict markers. Upper and lower are
used instead of ours and theirs because those meanings reverse during rebase.

| Key           | Action                                  |
|---------------+-----------------------------------------|
| =SPC . c n/p= | Next / previous conflict                |
| =SPC . c u/l= | Keep upper / lower side                 |
| =SPC . c a=   | Keep all sides                          |
| =SPC . c b=   | Keep the base revision                  |
| =SPC . c 0=   | Keep neither side                       |
| =SPC . c r=   | Refine conflict highlighting            |
| =SPC . c e=   | Resolve the current conflict with Ediff |

Inside Magit, =j/k= and =n/p= move by section, =^= moves to the parent section,
=TAB= expands or collapses, =RET= visits, =h= opens the dispatch menu, and =q=
or =.= restores the previous buffer. The original =j= jump and =k= discard
commands remain available as =h j= and =h k=. In Transient menus, =ESC= returns
to the parent menu or closes the top-level menu; =C-q= exits the entire stack.

Its top row opens my common source and configuration directories through
Dirvish, followed by recent projects and recent files. Backtick returns to it

suderman/dashboard= works everywhere without using the leader map.

** IBuffer and Treemacs

I use IBuffer to answer "what is open?" and Treemacs to answer "where is this
file?" Visiting a buffer can update the visible tree. Pressing comma on a tree
node opens IBuffer on the same file. Meow stays off in both views so their own
maps win.

*** IBuffer

| Key       | Action                                                       |
|-----------+--------------------------------------------------------------|
| =j / k=   | Move by row                                                  |
| =l=       | Visit buffer and update visible Treemacs, or toggle a group  |
| =h / ,=   | Close IBuffer and restore the previous window               |
| =S=       | Toggle contextual Treemacs without leaving IBuffer           |
| =m=       | Toggle the current mark without moving                       |
| =M=       | Mark every visible buffer                                    |
| =t=       | Invert marks; =M t= clears all marks                         |
| =u / U=   | Unmark without moving / unmark all                           |
| =.=       | Open Dirvish for the selected buffer or project              |
| =,=       | Close IBuffer and restore the previous window                |

Left click visits a buffer. Middle click toggles its mark. Non-project images
have their own group; other non-project buffers remain in the default group.

*** Treemacs

| Key          | Action                                              |
|--------------+-----------------------------------------------------|
| =j / k / n=  | Next / previous / next node                         |
| =h / u=      | Move the root up                                     |
| =l=          | Visit a file or directory in the previous editor     |
| =TAB=        | Expand or collapse the current node                   |
| =RET / o=    | Open file or make a directory the root               |
| =a=          | Add a file, or a directory when the name ends in =/= |
| =c / d / r=  | Copy / delete / rename                               |
| =g=          | Refresh                                              |
| =t=          | Toggle file watching                                 |
| =,=          | Open IBuffer in the selected tree context            |
| =.=          | Open Dirvish in the selected tree context            |
| =S=          | Toggle Treemacs visibility                            |
| =q=          | Close Treemacs                                       |
| =?=          | Treemacs help                                        |

TAB is the only keyboard expansion control; =H= and =L= are inert. Single left
click opens files and toggles directories. Middle click toggles a node without
visiting it. Treemacs follows the selected buffer's file, even when it has no
Imenu tags. After one second of idle time it follows the current Imenu tag,
including headings in Org files.

| Context | Keys                  | Action                                      |
|---------+-----------------------+---------------------------------------------|
| Dirvish | =h / j / k / l=       | Parent / next / previous / open             |
| Dirvish | =f=                   | Toggle full-frame layout                    |
| Dirvish | =H / L=               | Directory history backward / forward        |
| Dirvish | =m / M / t=           | Toggle mark / mark all / invert marks       |
| Dirvish | =u / U=               | Unmark without moving / unmark all          |
| Dirvish | =c / x / v=           | Stage copy / stage cut / paste              |
| Dirvish | =d / X=               | Flag for deletion / delete flagged files    |
| Dirvish | =a / r=               | Create / rename                             |
| Dirvish | =. / ,=               | Close Dirvish / replace it with IBuffer     |
| Dirvish | =g / I / i=           | Refresh / file information / toggle dotfiles |
| Dirvish | =s / z=               | Sort / quick access                         |
| Dirvish | =/ / ?=               | Search here / show current bindings         |
| Dirvish | =SPC=                 | Meow keypad                                 |
| Dirvish | =q=                   | Close Dirvish                               |
| Image   | =n / p=               | Browse images in cyclic alphabetical order |
| Image   | =h=                   | Move left                                   |
| Image   | =, / .=               | Open IBuffer / Dirvish                      |
| Image   | =SPC=                 | Keep Meow's keypad                         |
| Image   | =+= / === / =-=       | Zoom in / zoom in / zoom out               |
| Image   | =r / R=               | Rotate clockwise / counterclockwise        |
| Image   | =0=                   | Reset image transformations                |

Dirvish =c= and =x= stage the marked files, or the current file when nothing is
marked. Copies remain staged after =v=; cuts clear once the move starts.
Period opens the full-frame layout when no other window is visible; with splits
or Treemacs it uses only the selected editor window. The =f= key toggles between
those layouts. Comma closes a full-frame layout before opening IBuffer, while a
split-window Dirvish is replaced in place. Closing IBuffer restores the prior
editor window.
Dotfiles start hidden in the parent and current panes, and =i= toggles them
together without status messages. The preview remains unfiltered. Deleting a
file kills its unmodified visiting buffer, while modified buffers still require
confirmation. Use =M-x revert-buffer= when another program changes the
directory. The =?= popup reads the current bindings instead of Dirvish's default
command menu. The original menu remains available through =M-x
dirvish-dispatch=.

Animated images autoplay and loop.
