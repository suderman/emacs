* About

This is the Emacs config I use every day. I tune it around how I edit, switch
projects, and manage windows. It is not a starter kit. It has my paths, my
keymap, and a few experiments that earned their place by solving something
annoying.

[[https://github.com/meow-edit/meow][Meow]] controls modal editing. [[https://github.com/suderman/meow-purrsist][meow-purrsist]] keeps selections adjustable by
motion. Built-in =project.el= supplies project data. IBuffer lists open buffers
by recency or by project, Dirvish handles the file tree and file management,
and Magit handles Git. Vertico, Orderless, Consult, Marginalia, and Embark
handle minibuffer completion. Corfu shows in-buffer completion, with Eglot
supplying language-server results when the server is available.

Some choices are a little odd on purpose. Comma opens IBuffer, period opens
Dirvish, and semicolon repeats edits. =SPC= is both Meow's keypad and my leader
key. IBuffer and Dirvish pass file and project context back and forth instead of
acting like separate tools.

The editing map starts with selections, then applies changes to them. Dirvish
cleans up Dired. Markdown preview runs Pandoc and refreshes after each save.
Stylix supplies the colors, while Doom Modeline and Nerd Icons handle the lower
status bar and file symbols. Image mode cycles through a directory, transforms
images in place, and starts animated images automatically.

* Run it

#+begin_src sh
nix run github:suderman/emacs
#+end_src

That runs the configuration bundled in the Nix store. To edit it live, clone
it to =~/.config/emacs=, or load a checkout with =nix run . -- --init-directory
"$PWD"=, then press =F5= to reload after a change. [[file:docs/install.org][Install]] covers the
desktop package and the Android APK.

* Common keys

=SPC ?= draws the current view's keys on a keyboard, and Which-Key lists each
leader group after =SPC=. These are the keys I use most.

** Getting around

| Key         | Action                                   |
|-------------+------------------------------------------|
| =,=         | IBuffer, starting on the previous buffer |
| =.=         | Dirvish for the current file             |
| =\=         | Toggle the file sidebar                  |
| =`=         | Dashboard                                |
| =<= and =>= | Previous and next buffer                 |
| =SPC SPC=   | =M-x=                                    |
| =SPC ?=     | Keyboard cheatsheet for this view        |
| =C-c m=     | Mail                                     |
| =F5=        | Reload the configuration                 |

The dashboard opens on demand rather than at startup. Its top row opens common
source and configuration directories through Dirvish, followed by recent
projects and recent files. Backtick opens it from IBuffer and Dirvish too.

** Editing in Normal state

Meow selects first, then acts. Movement extends an active selection.

| Key              | Action                                                 |
|------------------+--------------------------------------------------------|
| =hjkl=           | Move                                                   |
| =w= =e= =b=      | Next word start, word end, previous word               |
| =m=              | Select a word; repeat to grow to the enclosing thing   |
| =M=              | Select a line; repeat for a rectangle, then the buffer |
| =z=              | Step the selection back                                |
| =i= =a=          | Insert before or after                                 |
| =I= =A=          | Insert at the line start or end                        |
| =c= =v=          | Copy and paste                                         |
| =x=              | Cut, then insert                                       |
| =d= =D=          | Delete, or delete the line, without the kill ring      |
| =X=              | Cut whole lines and stay in Normal                     |
| =u= =y=          | Undo and redo                                          |
| =;=              | Repeat the last edit                                   |
| =/= then =n= =p= | Search, then next and previous match                   |
| =f= =t=          | Find or move till a character                          |
| =s=              | Surround prefix                                        |
| =J= =K=          | Move lines or an Org subtree                           |
| =H= =L=          | Outdent and indent, or promote and demote in Org       |
| =o=              | Fold or unfold the block on this line                  |
| =[= =]= ={= =}=  | Previous, next, parent, and child block                |
| ~=~              | Format the buffer                                      |
| =Q=              | Kill the buffer                                        |

** Windows

| Key         | Action                             |
|-------------+------------------------------------|
| =M-h/j/k/l= | Focus the window in that direction |
| =M-H/J/K/L= | Move the divider                   |
| =M-u= =M-i= | Split below or right               |
| =M-w=       | Close the window                   |
| =M-z=       | Zoom the window                    |
| =M-n= =M-N= | New frame or tab                   |

These work in every view, including IBuffer, Dirvish, and Magit. At the edge
of Emacs they hand off to the surrounding terminal multiplexer.

** Leader

| Key       | Group                                    |
|-----------+------------------------------------------|
| =SPC ,=   | Buffers                                  |
| =SPC .=   | Files and bookmarks                      |
| =SPC /=   | Consult searches                         |
| =SPC g=   | Git, hunks, and conflicts                |
| =SPC o=   | Org states, planning, archive, and views |
| =SPC t=   | Toggles                                  |
| =SPC w=   | Windows                                  |
| =SPC q=   | Quit, reload, pull, and upgrade          |
| =SPC TAB= | Fold the buffer, or open all but drawers |
